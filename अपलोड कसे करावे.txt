साखरपुडा: २४ फेब्रुवारी; मेहंदी: २५ फेब्रुवारी; हळद: २६ फेब्रुवारी.
स्थळ: सनाबिल बँक्वेट्स, मरोळ, अंधेरी पूर्व, मुंबई.

ही ZIP आधी उघडा (Extract / Unzip करा).
index.html ही पूर्ण पत्रिका आहे. चित्रे, अक्षरशैली, अ‍ॅनिमेशन आणि काउंटडाउन त्याच फाईलमध्ये आहेत. वेगळे assets किंवा npm build आवश्यक नाही.

GitHub Pages वर अपलोड:
१. GitHub वर सार्वजनिक repository तयार करा किंवा योग्य repository उघडा.
२. Add file → Upload files मधून ZIPमधील index.html, .nojekyll आणि README.md अपलोड करा. ZIP फाईल स्वतः अपलोड करू नका. हे files थेट repository च्या मुख्य पातळीवर ठेवा.
३. Commit changes करा.
४. Settings → Pages → Build and deployment मध्ये Source: Deploy from a branch निवडा.
५. Branch: main, Folder: / (root) निवडून Save करा. तुमच्या repository ची मुख्य branch वेगळी असल्यास ती निवडा.
६. GitHub Pages चे deployment पूर्ण झाल्यावर त्याच पानावर प्रकाशित लिंक दिसेल. Actions मध्ये deployment ची स्थितीही पाहता येईल.

.nojekyll हा लपलेला, रिकामा file आहे. फोनवर तो दिसत नसला तरी ही साधी HTML पत्रिका त्याशिवायही उघडते.

स्थानिक प्रीव्ह्यू: index.html ब्राउझरमध्ये उघडा. मुखपृष्ठावरील पत्रिका उघडा यावर एकदा स्पर्श करा, नंतर खाली स्क्रोल करा. EN / मराठी बटणातून भाषा बदला.
पत्रिका वाचण्यासाठी इंटरनेट आवश्यक नाही; Maps, Google Calendar आणि ऑनलाइन शेअरिंगसाठी इंटरनेट लागते.

आकाश मोरे आणि रूपल ऐरे यांची नावे, वर्ष, मुहूर्त, कार्यक्रमांच्या तारखा आणि Maps लिंक दिलेल्या माहितीनुसार आहेत. इतर कौटुंबिक नावे, उपस्थितीचा संपर्क आणि कॅलेंडरमधील ३ तासांचा कालावधी अंतिम करायचे आहेत.

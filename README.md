# आकाश आणि रूपल — पैठणीतील शुभविवाह

Standalone animated Maharashtrian wedding invitation with all images and fonts embedded in `index.html`.

Target: 28 February 2027, 12:15 PM IST. The live countdown updates every second.

Upload `index.html`, `.nojekyll` and this README to your public GitHub repository root. In Settings → Pages, select “Deploy from a branch”, the main branch and `/ (root)`, then Save. Do not upload the ZIP itself in place of the extracted files.

No build, external assets or package installation is required. Open index.html directly for an offline preview. Maps, Calendar and online sharing require internet.

Other family names, RSVP contact and the calendar duration still need final confirmation.
